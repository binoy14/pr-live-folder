How it works

The extension fetches github.com/pulls?q=… with your browser session — the same page you'd see after clicking "Pulls" on GitHub. GitHub serves its own React frontend data (JSON), which the extension reads directly; an HTML fallback covers GitHub's older UI. A tab is created for each new PR and removed when its PR closes or merges.

If you're not signed in to github.com, the extension shows a sign-in hint — open github.com and sign in, then hit Sync.
